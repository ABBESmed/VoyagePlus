# VoyagePlus

VoyagePlus est un projet de site de voyage réalisé pendant ma formation Développeur Web et Web Mobile.

## Technologies utilisées
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Git / GitHub

## Fonctionnalités
- Page d'accueil responsive
- Connexion utilisateur
- Inscription utilisateur
- Formulaire de contact
- Système de réservation
- Gestion des passagers
- Base de données MySQL

## Structure du projet
- FRONT-END : pages HTML/CSS/JS/PHP côté utilisateur
- BACK-END : connexion à la base de données, login, inscription, réservation, contact

## Objectif
Ce projet m'a permis de pratiquer le développement front-end et back-end avec PHP et MySQL.
